# 🖥️ AVINYA.OS — Windows 11 Desktop Portfolio

> An interactive, ultra-smooth personal desktop operating system portfolio built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **Web Audio API**.

## 🌟 GitHub Repository Description (Short)

---

## 🚀 Key Features & Highlights

### 🪟 Windows 11 Fluent Window Engine
- **Draggable & Resizable Windows**: High-performance window dragging throttled with `requestAnimationFrame`.
- **Windows 11 Spring Physics**: Smooth Fluent Motion open/close scale animations (`stiffness: 380, damping: 28`).
- **Taskbar & Dock Controls**: Minimize to dock, un-minimize, focus z-index stacking, and active window previews.

### 🎮 Avinya Multi-Game Arcade Hub
- 🧠 **Tech Memory Match**: 8-bit memory matching game testing tech stack recall.
- 🐛 **Bug Hunter Mode**: Interactive code debugging challenge (React hooks stale closure, Java `.equals()` trap, SQL injection, Python mutable default parameters).
- 🏗️ **System Architecture Builder**: Scenario-based system design challenges (High-concurrency WebSockets, Enterprise AI RAG Platform).
- 🏆 **Recruiter MVP Unlocks**: High-score XP tracking that unlocks fast-track recruitment shortcuts.

### 🤖 Grounded AI Portfolio Assistant
- **Vinay AI Chatbot**: Instant grounded answers regarding projects, tech stack, GPA (8.46), and internship availability.
- **Voice Synthesis (TTS & STT)**: Integrated speech synthesis and voice microphone input.

### 💻 Interactive Terminal Shell
- **Full Shell Capabilities**: Supports `help`, `ls`, `cat`, `neofetch`, `theme matrix|cyberpunk|amber|dracula`, `about`, `projects`, `skills`.
- **Quick Command Chips**: One-click chip launchers for fast navigation.

### 🔎 Global Command Palette (`⌘K` / `Ctrl+K`)
- Instant fuzzy search across all applications, case studies, skill categories, and social links.

## 🛠️ Tech Stack

- **Frontend Core**: React 18, TypeScript, Vite
- **Styling & UI**: Tailwind CSS, Lucide Icons, Glassmorphism FX
- **Animations**: Framer Motion 11
- **State Management**: Zustand
- **Audio Engine**: Web Audio API (No external sound file downloads required!)

## 🚀 Quick Start

### 1. Installation
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
